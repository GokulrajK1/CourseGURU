# CourseGURU 

## Description
A Google Chrome extension designed to enhance Course Schedule Planner for Rutgers University students by integrating detailed professor evaluations from (www.ratemyprofessors.com) and personalized schedule recommendations powered by AI and machine learning.

## Setup 
1) Clone this project
2) Install node.js from (https://nodejs.org/en). This will install npm as well.
3) In the terminal or command line navigate to where you downloaded the project
4) Run the npm install command to install all dependencies 
5) Run the npm run build command to create a dist folder
6) Go to the extensions page on Google Chrome and turn on developer mode
7) Click on Load unpacked and then navigate to the dist folder and select it
8) Extension will be loaded in and can be used and tested.
